## MES（AIMES）查询通道打通记录
- 用户需求：查产线包装生产状况。MES MCP（`aimes-mes`，https://mes.sz.prime3c.com:8443/aimes-api/api/mcp/mes）已在 `~/.workbuddy-ai/mcp.json` 配置，但本会话未加载工具，走 HTTP JSON-RPC 直连。
- 关键坑：Windows curl 走 schannel 时因证书吊销检查失败（`CRYPT_E_NO_REVOCATION_CHECK`，exit 35），必须加 `--ssl-no-revoke`；并需 `--noproxy '*'`（环境有 https_proxy 干扰，直连返回乱码）。
- 服务端工具：`mes_query_list` / `mes_query_match` / `mes_query_options` / `mes_query_run`，query id 只有 `prod-status`。
- 线别代码：PA/PB/PE/PG/PH/PK/PL/PM —— **G 线 = PG**。
- 日期口径坑：method 197 等生产日类，要查生产日 D 必须传 `cond2=cond4=D+1`（传 D 只会得到 D-1）。method 057 是时间区间，`cond2/cond4` 相等会得到 0 行，必须 `cond2=D, cond4=D+1`。
- 常用 method：197 各线包装产出汇总（按线/日/白夜班）；057 依线别统计包装产能（含逐小时 pivot，列极宽，取前 15 列才是订单状态字段）。
- 辅助脚本：`C:\Users\yhwa\mes_call.py`（curl 封装 JSON-RPC，`call_tool(name, args)`）。
