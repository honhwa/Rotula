# 2026-10-21

## 工具箱元素改为可拖拽放置（拖到画布上放置）

需求澄清：用户最先说"设计界面所有元素改成可拖拽"，实际指的是**左侧工具箱里的工具无法拖到画布上**（画布上已有元素本来就能拖动/缩放/旋转）。

实现（分支 dev_261021，与主分支相同基线）：
- 新增 `src/Rotula.App/Editing/DropPlacement.cs`：`PlaceAt(element, bounds, x, y, doc, grid)` —— 把元素框的左上角放到落点，按网格吸附（吸附后再夹一次，防止越界），并夹在标签纸内。保持 WPF-free 便于单测。
- 新增 `src/Rotula.App/Controls/ToolboxDrag.cs`：拖放数据格式 `Rotula.ToolboxKind`，只传 kind，元素在 drop 时才创建（取消拖拽不会留下元素）。
- `DesignCanvas`：`AllowDrop = true`，`OnDragEnter/Over/Drop/Leave`；拖动时画虚线落位框 + 十字锚点（元素只测量一次后仅移动，避免每帧重绘测量）；drop 调 `MainViewModel.AddElementAt(kind, x, y)` 并聚焦画布。
- `MainViewModel.AddElement`（RelayCommand，点击用）改为转发到新的 `public void AddElementAt(kind, xDots?, yDots?)`；`ToolboxItem.Tip` 增加拖拽提示。
- `MainWindow.xaml/.cs`：工具按钮加 `PreviewMouseLeftButtonDown/Move/Up`，超过系统拖拽阈值才 `DragDrop.DoDragDrop`（先 `Mouse.Capture(null)` 释放按钮捕获），点击仍走原命令走默认位置。
- 新增 resx 键（en/es 必须同时有，AppLocalizationTests 会校验键一致与占位符一致）：`Status.DragToPlace`、`Tool.DragTip`（含 {0}）、`Tool.DragHelp`。
- 新增测试 `tests/Rotula.Tests/AppToolDropTests.cs`（9 项）：落点定位、越界夹取、网格吸附（注意 1mm@203dpi = 7.99 dots，非整数，用"整数步数"判定而非取模）、一次撤销、每种工具落位、点击仍走默认 24,24、纯数学用例。
- CHANGELOG `[Unreleased]/Added` 增加条目。

结果：`dotnet build` 通过；`dotnet test --filter ~Rotula.Tests.App` 677 项全绿；启动冒烟正常（标题 "Untitled - Rotula"）。

## 环境/验证注意事项
- 本机 dotnet 为 11.0.100-rc.2 预览版（有 NETSDK1057 提示，可忽略），构建用 `dotnet build src/Rotula.App/Rotula.App.csproj`。
